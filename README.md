
# TerraFind

TerraFind is a visual discovery app where users will be able to search for images by topic.

I chose a forest-green and warm-cream colour palette to give the interface a calm, nature-inspired identity.

The large headline makes the purpose of the app clear as soon as a user opens the page.

I also added topic suggestion chips and an empty-state message to guide users before search results are implemented in Part 2.
